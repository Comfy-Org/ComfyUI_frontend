# A11 API Contract Review Findings

## Summary
This PR introduces a new `remote_combo` widget type alongside the existing `remote` widget. The changes are primarily additive with careful schema evolution. One breaking change identified in the `useRemoteWidget` return type.

---

### [CRITICAL] Breaking Change: useRemoteWidget return type changed
- **File:** src/renderer/extensions/vueNodes/widgets/composables/useRemoteWidget.ts:196-199
- **Issue:** The return object no longer exports `getCacheEntry` and `cacheKey`. Instead it exports `getQueryKey`. Any code depending on these properties will break.
- **Fix:** If external consumers exist, provide a deprecation path or document the migration from `getCacheEntry`/`cacheKey` to `getQueryKey` and TanStack Query APIs.

---

### [MAJOR] New Exported Types Added to nodeDefSchema
- **File:** src/schemas/nodeDefSchema.ts:393-396
- **Issue:** Three new types are exported: `RemoteItemSchema`, `RemoteWidgetConfig` (already existed), `RemoteComboConfig`. These become part of the public API contract for node definitions.
- **Fix:** No fix needed - this is intentional API expansion. Document the new types for custom node authors.

---

### [MAJOR] New Schema Property: remote_combo on ComboInputOptions
- **File:** src/schemas/nodeDefSchema.ts:127-130
- **Issue:** The `zComboInputOptions` schema now includes an optional `remote_combo` field. This is a new input spec option that custom nodes can use. The schema enforces XOR between `remote` and `remote_combo`.
- **Fix:** Document the new `remote_combo` property for custom node developers. The XOR validation is correctly implemented via `zComboInputOptionsValidated`.

---

### [MODERATE] New Vue Query Dependency Added Globally
- **File:** src/main.ts:12-15,85-87
- **Issue:** TanStack Vue Query is now initialized at app startup and added as a global plugin. This changes the application initialization order and adds a new global provider.
- **Fix:** No fix needed - this is intentional infrastructure addition. Ensure the QueryClient configuration in `createAppQueryClient()` is appropriate for the app's caching needs.

---

### [MODERATE] New Context/Provider Contract: RemoteComboContext
- **File:** src/renderer/extensions/vueNodes/widgets/components/RemoteCombo/state.ts:5-21
- **Issue:** New `RemoteComboContext` interface and `RemoteComboKey` injection key exported. This establishes a new Vue provide/inject contract for the RemoteCombo component family.
- **Fix:** No fix needed - new internal API. Components using these must be wrapped in a `RemoteCombo.Root` provider.

---

### [MODERATE] DropdownItemShape Interface Added to Public API
- **File:** src/base/remote/itemSchema.ts:3-8
- **Issue:** New `DropdownItemShape` interface exported with `id`, `name`, `description?`, `preview_url?` properties. This becomes a contract for remote combo item data.
- **Fix:** Document this interface for consumers. Consider if this should be in a types file rather than mixed with utility functions.
