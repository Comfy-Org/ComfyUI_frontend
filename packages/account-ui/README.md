# @comfyorg/account-ui

The Vue view layer over `@comfyorg/account-core`: composables and components
for billing (Billing tab sections, add-credits, checkout) and sign-in. The host
keeps routing, windows, dialogs, translation and the payment provider's SDK.

## What a host loads

The package ships ES modules and type declarations only. It has no CSS of its
own: components render Tailwind 4 utility classes, and the host's Tailwind
build generates them.

1. Install the peers: `vue`, `@vueuse/core`, `@vueuse/integrations`, `reka-ui`,
   `primeicons`, `@comfyorg/design-system` and `tailwindcss`. These components
   do not need the `primeicons` CSS. Add `@stripe/stripe-js` only if you render
   `./billing/stripe` or `./billing/checkout`.
2. Import the design-system CSS in the stylesheet Tailwind processes. It brings
   the theme tokens (`bg-background`, `text-muted-foreground`, ...) and the
   icon plugin.
3. Add this package's `dist` to your Tailwind sources. Without it the classes
   the components use are never generated.

```css
@import '@comfyorg/design-system/css/style.css';

@source '../node_modules/@comfyorg/account-ui/dist';
```

The `@source` path is relative to the stylesheet. `dist` already contains the
class recipes from `@comfyorg/design-system` that the components use, so no
extra source is needed for them.

Icons are iconify classes (`icon-[lucide--info]`), generated by the
design-system CSS from the lucide set it depends on. The components do not use
primeicons; load `primeicons.css` only if your own markup does.

## Copy

The host translates. Billing tab and checkout components take a copy object:
`BillingBannerCopy`, `PlanRowCopy`, `CreditsCardCopy`, `AutoTopUpCardCopy`,
`CheckoutCopy` and so on. Entries that embed a value are functions, for example
`PlanRowCopy.activeMonthly(date)`, and dates are formatted with the `locale`
the host passes. `AddCreditsDialog` takes a `translate` function instead and
falls back to English without one.

## Example: a Billing tab banner

```vue
<script setup lang="ts">
import { BillingBanner } from '@comfyorg/account-ui/billing'
import type {
  BillingBannerAction,
  BillingBannerCopy,
  BillingBannerView
} from '@comfyorg/account-ui/billing'

const copy: Pick<BillingBannerCopy, 'dismiss' | 'actions'> = {
  dismiss: 'Dismiss',
  actions: {
    addCredits: 'Add credits',
    updatePayment: 'Update payment',
    verifyPayment: 'Verify payment',
    contactSupport: 'Contact support',
    resumePlan: 'Resume plan',
    choosePlan: 'Choose a plan',
    contactSales: 'Contact sales'
  }
}

const view: BillingBannerView = {
  kind: 'parked',
  title: 'Your account is on hold',
  body: 'Contact support to restore access.',
  action: 'contactSupport',
  href: 'https://support.comfy.org'
}

function onAction(action: BillingBannerAction) {
  console.info(action)
}
</script>

<template>
  <BillingBanner :view :copy @action="onAction" />
</template>
```

`planCheckoutBannerView` and `topupCheckoutBannerView` build a
`BillingBannerView` from the core's served banner state, and
`selectBillingBanners` orders a list of them and drops the ones that should not
show together.

## Entry points

| Entry point          | Contents                                                               |
| -------------------- | ---------------------------------------------------------------------- |
| `./billing`          | Billing client provider, composables, Billing tab and add-credits UI   |
| `./billing/checkout` | Checkout steps; needs `@stripe/stripe-js`                              |
| `./billing/stripe`   | Stripe payment form; needs `@stripe/stripe-js`                         |
| `./billing/catalog`  | Plan tier catalog                                                      |
| `./auth/*`           | Sign-in pieces: password rules, social buttons, Turnstile, region gate |
