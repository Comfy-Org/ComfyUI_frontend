# add-model-page

comfy.org, including its model pages, is now built from the private
repository `Comfy-Org/comfy-website`. Do not edit `apps/website` in this
repository and do not open a pull request here.

Tell the person that model pages are now added, updated and removed in
`Comfy-Org/comfy-website`, where the same `add-model-page` skill does the
work, and stop.
