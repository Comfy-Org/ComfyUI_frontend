# Operating system icons

`linux.svg` is the monochrome Tux icon distributed by
[Simple Icons](https://github.com/simple-icons/simple-icons).

The original Tux artwork was created by Larry Ewing using GIMP. Its creator
permits use and modification provided Larry Ewing (`lewing@isc.tamu.edu`) and
GIMP are acknowledged when asked. See the
[original permission](http://www.isc.tamu.edu/~lewing/linux/) and its
[Wikimedia Commons record](https://commons.wikimedia.org/wiki/File:Linux_logo.jpg).
