---
question: "Cloud APIを使い始めるにはどうすればよいですか？"
order: 14
---

Cloud APIを使うと、ご自身のアプリ、スクリプト、パイプラインからComfyUIのワークフローをComfy Cloudで実行できます。料金はプランと同じクレジット残高から差し引かれます。すべての有料プランにAPIアクセスが含まれ、同時に実行できるワークフロー数はStandard / Creator / Pro / Teamでそれぞれ**1 / 3 / 5 / 25**です。設定、認証、使用例については、[Cloud APIのドキュメント](https://docs.comfy.org/development/deploy/cloud)をご覧ください。
