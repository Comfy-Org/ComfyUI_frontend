# Converting a V2 pack to V4

One row per member or pattern of the V2 contract (`/comfy/api/v2.js`) that a
stored pack uses, and each zero-use member that was cut. "Packs / sites" is the
census of 128 stored V2 packs. "1:1" means the V4 member has the same name, the
same arguments and the same result for every use a stored pack makes; a "No"
row says what a converter must change.

Rules that apply to every row:

- A pack imports `comfy` from `/comfy/api/v4.js`, not `/comfy/api/v2.js`.
- Every member checks its arguments and throws a `TypeError` naming itself for
  one it cannot use. V2 ignored some of these and did nothing.
- An edit or view method that returned nothing in V2 now returns `true` when it
  applied and `false` when its entity is gone. A pack that ignores the result
  is unaffected.
- Hooks, resolvers and suppliers are synchronous. A V2 callback that was
  awaited (`onPromptSerialize`, a resolver with a `signal`) runs to completion
  when called.
- Nothing exists for a sandbox: no capability checks, no proxies, no guest-SDK
  services (see [Guest SDK members](#guest-sdk-members)).
